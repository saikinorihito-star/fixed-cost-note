# 固定費ノート v1.0

自分専用の固定費・サブスク管理用 Web アプリです。銀行口座・カード・メールには接続しません。料金・契約情報はアプリを開いた端末のブラウザ内に保存され、サーバーには送信されません。

## 主な機能
- カテゴリーごとの契約登録、編集、解約済み化、削除（確認あり）
- 毎月払い・毎年払いの月平均／年間換算額、カテゴリー別集計
- 更新日の **2日前、前日、当日** にアプリ内で警告（アプリを開いているときのみ）
- 料金・請求周期を変更して保存すると、変更日・変更前後の値を自動記録
- カテゴリー追加・名称変更・削除（使用中の場合は削除不可）
- JSON バックアップの保存・復元

## GitHub Pages で公開（Mac）
1. GitHub で新しいリポジトリ `fixed-cost-note` を **Public** で作成します。GitHub FreeのPagesを使うためです。登録した実際の契約データはリポジトリにアップロードしません。
2. このフォルダーの `index.html`, `manifest.webmanifest`, `icon.png`, `icon-512.png` をリポジトリ直下にアップロードします。 `README.md` は任意です。
3. GitHub リポジトリの **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save** を選択します。
4. **Settings → Pages** に表示された `https://<GitHubユーザー名>.github.io/fixed-cost-note/` にアクセスします。
5. iPhone の Safari でURLを開いて、「共有」→「ホーム画面に追加」→（表示されたら）「ウェブアプリとして開く」→「追加」を選びます。
6. ホーム画面のアイコンからアプリを開き、契約情報を登録してください。

## 重要な注意
- 無料のGitHub Pagesでは公開リポジトリが必要です。**プログラムは公開されますが、入力した契約情報は公開されません。** ただしブラウザに保存した情報は暗号化されていません。第三者が端末・ブラウザにアクセスできる場合は閲覧可能です。
- データはiPhoneとMacで自動同期されません。iPhoneのSafariとホーム画面Webアプリでは、保存領域が異なる場合があります。**普段使うホーム画面アプリで情報を登録**してください。
- ブラウザの保存領域を消去したり、アプリを削除した場合はデータが消える可能性があります。**登録後は設定 → バックアップ保存**でJSONを保存してください。復元時は現在のデータが置き換わります。
- 更新日通知は**アプリ内のみ**。端末を閉じている間は通知が来ません。更新予定から2日以内になってアプリを開くと警告が出ます。
- サービス事業者の料金変更や実際の銀行口座・カード引き落としは自動監視しません。料金を手動で編集すると自動で改定履歴が記録されます。
- このバージョンでは、支払日と契約更新日を別々には管理していません。更新日を基準に管理します。
- GitHub Pagesへのアップロードは、**index.htmlの他に3つの補助ファイル**も入れることを推奨します。index.html単体でも主要機能は使用できますが、ホーム画面アイコンは標準表示になる可能性があります。

## ファイル
- `index.html` : 画面・デザイン・処理のすべて
- `manifest.webmanifest` : ホーム画面追加向け情報
- `icon.png`, `icon-512.png` : アイコン
